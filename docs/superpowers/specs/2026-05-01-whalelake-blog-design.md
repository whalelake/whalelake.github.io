# whalelake Blog Design

## Direction

Build `whalelake.github.io` as a personal magazine for development, current affairs, data analysis, daily notes, and project records. The visual direction is a modern lab magazine with editorial weight: clean, sharp, readable, and slightly newspaper-like without feeling old.

## Platform

Use GitHub Pages with Jekyll. The repository name should be `whalelake.github.io`, which publishes to `https://whalelake.github.io`. A future custom domain can be added through GitHub Pages settings and a `CNAME` file when the domain is ready.

## Content Model

Posts live in `_posts` as Markdown files. Each post has front matter for `title`, `date`, `category`, `excerpt`, and optional `featured`. Core categories are:

- Development
- Current Affairs
- Data Analysis
- Life
- Projects

## Pages

- Home: magazine-style front page with featured story, latest posts, category rail, and project notebook section.
- Archive: chronological list of all posts grouped by category cues.
- About: short editor profile and editorial interests.

## Design

Use strong typographic hierarchy, restrained color, crisp dividers, and compact article cards. The palette avoids one-note blue or purple themes: ink black, paper white, sea green, brass, and muted red accents.

## Implementation Notes

Keep the site dependency-light and GitHub Pages compatible. Avoid JavaScript-heavy features for the first version. Prefer semantic HTML, accessible navigation, responsive layouts, and Markdown-first publishing.
